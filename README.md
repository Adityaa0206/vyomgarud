VyomGarud – UAV Systems Landing Page

A modern, responsive landing page built for **VyomGarud**, a conceptual UAV (Unmanned Aerial Vehicle) and aerospace technology brand.  
This project was created as part of a Web Developer Intern Assignment and focuses on clean UI, strong branding, and high-quality frontend development practices.

Live Demo: https://vyomgarud-alpha.vercel.app/  
GitHub Repository: https://github.com/Adityaa0206/vyomgarud

---

## 🚀 Features

### 🎯 **Hero Section**

- Bold branding and tagline
- CTA buttons (Request Demo, Capabilities)
- Drone preview card with hover glow
- Background graphic with subtle gradients

### 🛰️ **About Section**

- Overview of VyomGarud
- Tagline block
- Contact & Brand color details

### ⚙️ **Capabilities / Products Section**

- 3 modular product cards
- Hover animations using Framer Motion
- Clean grid layout

### ⭐ **Highlights Section**

- Mission-critical features
- Security, endurance & autonomy features

### 📬 **Contact Section**

- Simple contact form (frontend only)
- Company information
- Footer branding

How to Run the Project Locally

### 1. Clone the Repository

git clone https://github.com/Adityaa0206/vyomgarud.git
cd vyomgarud

2. Install Dependencies

npm install

3. Start Development Server

npm run dev

Site will run at:

http://localhost:5173

4. Build for Production

npm run build
