# VyomGarud - Landing Page

React + Tailwind single-page landing page for the VyomGarud Web Developer Intern assessment.

## Run locally

1. npm install
2. npm run dev
3. Open the local dev URL shown in terminal

## Tech stack

- React (Vite)
- Tailwind CSS
- Framer Motion (animations)

## Design

- Dark, modern aesthetic
- Colors: charcoal, white, orange (#ff7b00)
- Fonts: Poppins, Inter

## Submission checklist

- GitHub repo link with commits
- README with setup and design notes
- Screenshot(s) or GIF of mobile & desktop
- Optional: Live demo link (Vercel or Netlify)
